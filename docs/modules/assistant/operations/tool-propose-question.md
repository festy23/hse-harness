# propose_question

## Метод

Pi tool `propose_question`; [общая оболочка](tools.md).

## Описание

Подготовка вопроса с отдельным подтверждением.

## Ресурсы

[Approvals.propose](../../study/operations/propose-approval.md).

## Входные параметры

| Название | Тип | Обязательность | Описание |
|---|---|---|---|
| chat | string | Да | Канонический ID разрешённого чата |
| text | string | Да | 1..3500 символов |

## Выходные параметры

`{draft:string}`; draft=id из propose.

## Результат в случае успеха

Вернуть результат в [общей JSON text оболочке](tools.md).

## Результат в случае ошибки

Отклонить execute Promise; завершённые внешние/локальные действия не откатывать.

## Алгоритм работы

1. Вызвать approvals.propose(question,{chat,text},Date.now(),ctx).
2. Вернуть {draft:id}. Вызов не должен отправлять текст в группу; внешний вопрос исполняет отдельный approve. ownerTurn здесь не проверяется.

## Ошибки

| Код | Статус | Message | Описание |
|---|---|---|---|
| dependency | exception | Из Approvals | Запрещённый чат/пустой текст/показ/запись |
