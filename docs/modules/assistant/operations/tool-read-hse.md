# read_hse

## Метод

Pi tool `read_hse`; [общая оболочка](tools.md).

## Описание

Чтение официальной страницы.

## Ресурсы

[HSE HTTP](../http/read-hse.md), Core HTML compute.

## Входные параметры

| Название | Тип | Обязательность | Описание |
|---|---|---|---|
| url | string | Да | HTTPS hse.ru/subdomain |
| offset | integer | Нет | 0..1000000; default 0 |

## Выходные параметры

`{url,text,totalCharacters,nextOffset?,links}` из HTTP-контракта.

## Результат в случае успеха

Вернуть результат в [общей JSON text оболочке](tools.md).

## Результат в случае ошибки

Отклонить execute Promise; завершённые внешние/локальные действия не откатывать.

## Алгоритм работы

1. Вызвать readHse(url,offset,ctx).
2. Вернуть результат; при наличии nextOffset системная инструкция должна требовать продолжить чтение. Инструмент сам не обходит ссылки и не сохраняет отдельную память предметов.

## Ошибки

| Код | Статус | Message | Описание |
|---|---|---|---|
| dependency | exception | Из readHse | URL, HTTP, текстовый формат, лимит/compute |
