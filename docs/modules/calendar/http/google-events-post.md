# Создание события Google

## Метод

`POST /calendars/{calendarId}/events`.

## Описание

Создание события Google.

## Ресурсы

[Google transport](google-request.md), [Google event mapping](../operations/google-mapping.md).

## Входные параметры

| Название | Тип | Расположение | Обязательность | Описание |
|---|---|---|---|---|
| calendarId | string | path | Да | encodeURIComponent выбранного id |
| body | GoogleEvent | body | Да | encode(event), включая стабильный id |

## Выходные параметры

Ответ API не используется.

## Результат в случае успеха

HTTP 2xx; void.

## Результат в случае ошибки

Пробросить ошибку [транспорта](google-request.md), кроме явно заданных ветвей алгоритма. Локальный Store этим методом не изменяется.

## Алгоритм работы

1. Вызываться только после 404 PUT. Отправить body без дополнительной мутации полей.
2. При 409 вернуть ошибку вызывающему put для его единственного повторного PUT. Иной исход вернуть без локального повтора.

## Ошибки

| Код | Статус | Message | Описание |
|---|---|---|---|
| dependency | non-2xx/2xx | Из transport | 409 обрабатывает put |
