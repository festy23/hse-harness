# Кэши Calendar

| Кэш | Тип и форма | Время жизни и размер | Формирование и инвалидация |
|---|---|---|---|
| Объекты аккаунтов | In-memory; по одному `ICloudAccount`, `Google`, `YandexAccount` в замыкании registry | До уничтожения registry, максимум 3 объекта | Создать лениво при первом вызове провайдера; явной инвалидации нет |
| Коллекция роли | In-memory; `collection: CalendarCollection \| undefined` | До уничтожения календаря; максимум по одному на роль | Сохранить результат factory только после проверки abort; ошибку открытия не кэшировать; конкурентные первые вызовы не объединять |
| Google tokens | In-memory; `{access_token,refresh_token,expires_at}` | До уничтожения Google; одна запись | Первый token читает google.json; refresh заменяет запись; внешние изменения файла после загрузки не перечитывать |
| Google refreshing | In-memory; `Promise<string> \| undefined` | Пока выполняется один refresh | Все ожидающие token должны ждать общий Promise; finally должен очищать его при успехе и ошибке |

Снимок календаря и sync token должны быть долговечным состоянием, а не кэшем. Списки событий не должны кэшироваться между вызовами.
