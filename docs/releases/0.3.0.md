# HSE HARNESS 0.3.0

Бот продолжает принимать команды и отправлять известные напоминания, когда один
из учебных источников или инициализация модели недоступны. Выпуск включает
исправления из PR #2 и исправление гонки heartbeat в его CI-тесте.

## Изменения

- Независимые циклы Telegram, почты, календаря, Pi и напоминаний; быстрые
  `/help` и `/status` выполняются отдельно от медленных команд.
- Ограниченные сетевые операции с отменой; восстановление Telegram и продолжение
  истории без пропусков, ложных удалений и преждевременного подтверждения updates.
- IMAP-таймаут закрывает соединение и сохраняет позицию чтения. Неоднозначные
  отправки и календарные изменения сохраняют намерение для проверки результата.
- HTML и календарные повторения обрабатываются вычислительным worker. Поиск
  оригинальной истории Pi уступает event loop, сохранения состояния объединяются
  с сохранением гарантий fsync и атомарной замены файла.
- Supervisor 1.0.1 следит за worker во время подготовки обновления. Потерянное
  подтверждение активации не позволяет прервать уже принятую операцию.
- `/status` показывает задержку event loop, возраст операций и состояние источников.

Pi 1.0.2, его JSONL-память, operations schema 2 и IPC protocol 1 сохранены.
Данные и учётные записи остаются в личном каталоге установки.

## Переход с 0.2.x

Для установки нового supervisor нужен один обслуживаемый перезапуск.
Дождись завершения текущих операций. На VPS с systemd выполни от пользователя,
который устанавливал сервис:

```sh
hse-harness service stop
npm install -g @ivan-boss/hse-harness@0.3.0
hse-harness service install
hse-harness updates status
hse-harness service status
```

`service install` устанавливает новый engine и запускает сервис. Существующие
proxy drop-ins нужно сохранить. Если автоматическое применение ранее отключено,
`hse-harness updates enable` разрешает переключение на установленный выпуск.
Проверь `/status` в Telegram после запуска.

При запуске в терминале заверши текущую работу, останови прежний процесс,
установи пакет и снова выполни `hse-harness start`. Обычные дальнейшие совместимые
обновления worker сохраняют механизм переключения без ручной остановки.

## Известные ограничения

Синхронные участки Pi SDK, XML-парсера tsdav и одна полная JSON-сериализация
состояния остаются на основном потоке. В локальном benchmark snapshot 50 МиБ
дал p95 65,12 мс, выше цели 50 мс; соблюдение SLO на выделенной среде не заявляется.
Подробные контракты, результаты и характеристики машины приведены в
[спецификации](../async-hardening-spec.md).

Публикация npm сама по себе не обновляет supervisor уже работающего сервиса.
