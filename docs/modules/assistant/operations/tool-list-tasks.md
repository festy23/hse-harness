# list_tasks

## Метод

Pi tool `list_tasks`; [общая оболочка](tools.md).

## Описание

Чтение текущих работ.

## Ресурсы

[Calendar.listTasks](../../calendar/operations/study-calendar.md).

## Входные параметры

Пустой объект `{}`; иных параметров схема не задаёт.

## Выходные параметры

Task[]; поля и порядок из Calendar.listTasks.

## Результат в случае успеха

Вернуть результат в [общей JSON text оболочке](tools.md).

## Результат в случае ошибки

Отклонить execute Promise; завершённые внешние/локальные действия не откатывать.

## Алгоритм работы

1. Вызвать calendar.listTasks(ctx).
2. Вернуть полученный массив без дополнительной фильтрации. Обязательства без календарного события должны искаться в истории Pi, этим инструментом не синтезироваться.

## Ошибки

| Код | Статус | Message | Описание |
|---|---|---|---|
| dependency | exception | Из Calendar | Внешнее чтение, метаданные, отмена |
