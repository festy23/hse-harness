# notify_owner

## Метод

Pi tool `notify_owner`; [общая оболочка](tools.md).

## Описание

Личное важное уведомление.

## Ресурсы

Bot.send, Store.delivered, pi.turnId, SHA-256.

## Входные параметры

| Название | Тип | Обязательность | Описание |
|---|---|---|---|
| text | string | Да | 1..3500 символов |

## Выходные параметры

`{sent:true}` при выполненной либо ранее помеченной доставке.

## Результат в случае успеха

Вернуть результат в [общей JSON text оболочке](tools.md).

## Результат в случае ошибки

Отклонить execute Promise; завершённые внешние/локальные действия не откатывать.

## Алгоритм работы

1. Вычислить key=`notice:${pi.turnId}:${SHA256(text)}`.
2. Если !store.state.delivered[key], вызвать bot.send(text,undefined,key,ctx), затем установить delivered[key]=Date.now() и Store.save. При ошибке до сохранения повтор должен использовать тот же key.
3. Если delivered уже существует, не отправлять. Вернуть {sent:true}. Не использовать вместо финального ответа владельцу/сводки; этот запрет задаётся системной инструкцией, ownerTurn gate отсутствует.

## Ошибки

| Код | Статус | Message | Описание |
|---|---|---|---|
| dependency | exception | Из Bot/Store | Доставка, отмена, фиксация |
