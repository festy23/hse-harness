# Источники базы знаний по предметам ВШЭ

Проверено 3 октября 2026 года. Исследованы открытые официальные страницы ВШЭ. Образовательная программа, кампус, учебный год и выбранные предметы пользователя пока неизвестны; приведенные страницы отдельных программ и курсов — примеры структуры источников, а не его учебный план.

## Что доступно публично

- [Каталог учебных курсов](https://www.hse.ru/edu/courses/) содержит фильтры по кампусу, образовательной программе, учебному году, уровню обучения, преподавателю, статусу и периодам проведения. В результатах указаны год, связь с программой, курс обучения, модули, преподаватели и кредиты. Это позволяет искать конкретное предложение дисциплины, а не только совпадение названия.
- [Учебные планы программы «Экономика»](https://www.hse.ru/ba/economics/learn_plans) разделены по году набора и курсам обучения; на странице есть переход к учебным курсам программы. Это подтверждает необходимость различать **год набора** и **учебный год**. В полученном текстовом представлении ячейки с документами плана пусты: доступность названия раздела сама по себе не подтверждает успешную загрузку плана.
- [Пример публичной карточки дисциплины](https://www.hse.ru/edu/courses/1163544036) содержит ID 1156254, учебный год 2026/2027, образовательную программу, третий курс и первый модуль, преподавателей, элементы контроля и раздел «Промежуточная аттестация». Формула использует веса 0.3 для компонента «Кейсы», 0.1 для «Тесты», 0.1 для «Активность на семинарах» и 0.5 для «Проект + Защита». Правила защиты дополнительно описаны в элементе контроля. Карточка также ссылается на дополнительные материалы в LMS. Эта дисциплина не сопоставлена с пользователем.

## Правила оценивания

[Справочник учебного процесса ВШЭ](https://www.hse.ru/studyspravka/ocenki_hse) указывает, что формула и система оценивания фиксируются в программе учебной дисциплины (ПУД). Возможны взвешенные суммы, нелинейные выражения, ранжирование и другие правила. Для нескольких периодов ПУД должна описывать промежуточные и окончательную оценки. Округление также описывается в ПУД; справочник устанавливает арифметическое округление к ближайшему целому, если не определено иное. Упоминаются элементы контроля, объявленные блокирующими в ПУД.

**Вывод для спецификации:** извлекать нужно не только веса «накопа», но и периоды применимости, итоговую/промежуточную формулу, компоненты, правила округления, шкалы, блокирующие условия и исключения. Универсальную линейную формулу для всех предметов предполагать нельзя. Это проектный вывод из перечисленных официальных правил, а не установленная ВШЭ схема базы данных.

## Что нужно для персонального сопоставления

Предлагаемый набор данных пользователя, выведенный из структуры каталога и планов:

1. Точное название образовательной программы или ссылка на нее; кампус.
2. Учебный год, для которого нужна база; год поступления/набора и текущий курс.
3. Выбранные предметы, специализация/траектория, майнор и факультативы; по возможности индивидуальный учебный план.
4. Группа/поток и преподаватели — если для похожих названий остаются несколько подходящих карточек.

Для каждой записи сохранять исходный URL и ID карточки, учебный год, программу, период и дату проверки. Одного названия предмета и слов «третий курс» недостаточно для надежного выбора версии.

## Ограничения автоматического покрытия

- Исследование подтверждает существование открытых карточек с формулами; оно **не подтверждает**, что формулы всех предметов пользователя опубликованы и доступны.
- Ссылка на LMS в открытой карточке не дает содержимого дополнительных материалов. Закрытые источники здесь не исследовались.
- Учебный план программы и публичный каталог не устанавливают личный выбор студента. Нужна сверка списка обязательных и выбранных дисциплин.
- Отсутствующие правила, неоднозначное сопоставление, устаревшие годы и конфликты с сообщениями преподавателей должны оставаться явно обозначенными пробелами. Формулу нельзя достраивать по аналогии с соседним курсом.
- Полноту следует показывать как список предметов с состояниями «правила найдены», «есть пробел», «есть конфликт», с источниками; обещание «все формулы известны» допустимо лишь после проверки полного персонального списка. Это рекомендация для реализации, а не свойство исследованных страниц.
