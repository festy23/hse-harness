# Спецификация HSE Harness

## Область действия и источники

Спецификация фиксирует реализованное поведение HSE Harness в ревизии `f3bacd3`.
Подтверждённые факты исходного кода этой ревизии определяют контракты текущей системы.
Термины определены в [CONTEXT.md](../../CONTEXT.md). Новые продуктовые требования
и изменения реализации должны оформляться отдельно от документирования текущего поведения.

## Форма контрактов

Постоянный публичный HTTP/gRPC сервер приложением не предоставляется. Google OAuth
временно открывает loopback [GET /callback](cli/http/google-callback.md). Внешние HTTP-вызовы
определяются в каталогах `http/` соответствующих модулей; внутрипроцессные операции,
CLI и IPC — в `operations/`. Фоновые циклы определяются в `jobs/`.
PostgreSQL и Redis не используются. Физические файловые форматы определяются в
`database/README.md`; DBML и его SVG-представление для отсутствующей SQL-схемы не создаются.

Ресурс должен иметь одно основное описание; использующий его модуль ссылается
на это описание. Описанные гарантии ограничиваются реализованными проверками,
порядком записи и протоколами внешних систем.
